create 3 to 6 folders depending on the updates being integrated...

*** A windows ISO contains some files in the root of the filesystem and some folders to boot the setup program
*** setup.exe in root and sources folder is used within a running windows, the boot.wim Windows PE copy of setup is used when ISO is booted
*** The 8GB install.wim file in the sources folder is an archive containing all Windows files in the standard folder structure
*** The 700MB boot.wim is also inside the sources folder and is the Windows Preinstallation Environment which contains the setup program and drivers used during Windows installation when booted from an ISO. Index 2 for Setup
*** The 800MB winre.wim is inside the install.wim archive. It contains the recovery environment files to be installed in a standard hidden partition. Since it's an archive inside another wim, another temp folder is needed to open and work within it and it must be repacked before the main install.wim is finalized 

*** Most updates that can be slipstreamed into the install ISO get inserted into install.wim
*** Any updates specific to the recovery environment are inserted into winre.wim 
*** Finally, some updates (for the installer itself, for example) don't use dism and just get extracted and copied into the ISO folder manually

c:\win11iso    - ** extract the original iso file into this folder first with 7zip ** Delete all files for new project
c:\win11mount  - empty - this will contain the extracted install.wim from the above iso and be a work folder
c:\win11update - put patches here, i.e. cumulative update, last preview and .net msu files from windows update catalog
*** USE BASE MONTHLY CUMULATIVE (2nd tues) WITH LAST PREVIEW UPDATE for Win11 and .NET - PREVIEW UPDATES WITHOUT BASE WILL ALLOW WINDOWSUPDATE TO INSTALL THE BASE PATCH WHEN INSTALL IS COMPLETE! :( ***

C:\win11reupdates - put winre update cab files here, if needed
c:\win11mountwinre - empty - will contain the extracted winre.wim for Safe OS Dynamic Update for Windows 11 - Windows recovery environment (WinRE)

c:\win11updates-cab - put Setup Dynamic Update cab files here. They will be manually extracted when needed

--1st check index number to modify within the install.wim file - probably 1 for Home or 6 for Pro
dism /get-imageinfo /imagefile:"c:\win11iso\sources\install.wim"

--convert .esd install file to wim if needed - probably only if you used windows media creation tool to dl the ISO - ESD has heavier compression
dism /Export-Image /SourceImageFile:c:\win11iso\sources\install.esd /SourceIndex:6 /DestinationImageFile:c:\win11iso\sources\install.wim /Compress:max /CheckIntegrity

--next mount install.wim from within extracted iso to the empty mount folder - note index below
dism /loglevel=1 /mount-wim /wimfile:"c:\win11iso\sources\install.wim" /index:6 /mountdir:"c:\win11mount"

========== Adding Safe OS Dynamic Update .cab file into winre.wim first - skip ahead if not needed ===============================================================================================
--mount winre.wim into temp directory - index 1 is used for winre.wim as its the only index used in this file 
Dism /Mount-Wim /WimFile:C:\win11mount\Windows\System32\Recovery\winre.wim /index:1 /MountDir:C:\win11mountwinre

--add update cab file into winre mount folder
Dism /Add-Package /Image:C:\win11mountwinre /PackagePath:"C:\win11reupdates"

--check if package installed correctly with 
Dism /Image:C:\win11mountwinre\ /Get-Packages

should show something like:
Deployment Image Servicing and Management tool
Version: 10.0.26100.5074

Image Version: 10.0.26100.7447           **Latest version of winre displayed here already

Packages listing:
...
Package Identity : Package_for_SafeOSDU~31bf3856ad364e35~amd64~~26100.7447.1.2   ***7447 is latest version
State : Installed
Release Type : Update
Install Time : 12/10/2025 4:35 AM            ***CURREnT DATE HERE

--cleanup and commit winre.wim file - when complete, win11mountwinre should be empty and winre.wim file in sys32/recovery will have the current date/time. Likely will give error at the end about files being in use but as long as mount folder is empty, alls good
dism /image:C:\win11mountwinre /cleanup-image /StartComponentCleanup /ResetBase

Dism /Unmount-Image /MountDir:"C:\win11mountwinre" /Commit
========= end winre update  ===============================================================================================================================================

-------------------------------------------------
--Use 7zip to open the Setup Dynamic Update cab file and extract it directly into the sources folder within c:\win11iso
-- verify matching files/folders will be overwritten. Language folders that are in the cab but not used in this iso can be safely ignored. This covers setup run from within an existing windows installation.
-- To also update the version of setup within Windows PE that's used when booted from an ISO image, use the same process above on boot.wim as was used on winre.wim

--add windows update .msu packages to the mounted WIM index
dism /loglevel=1 /add-package /image:"c:\win11mount" /PackagePath:"c:\win11updates"

--verify that the newly integrated packages appear correctly with current date/time
dism /image:"c:\win11mount" /get-packages

--save the changes and unmount the image - when complete, mount folder should be empty and sources\install.wim newer
dism /loglevel=1 /unmount-wim /mountdir:"c:\win11mount" /commit

possibly doesn't fully unmount (directory empty?) - still failed and folder was empty already - probably can skip this
dism /loglevel=1 /unmount-wim /mountdir:"c:\win11mount" /discard
